# 九州電力 スライド（ウェブ版）

九州電力についてのプレゼンテーション資料（A4横・全22ページ）を、
1ページずつ忠実に再現したウェブページです。

## 再現の方針

原資料の PDF から、各要素の位置・大きさ・色をすべて実測して組み直しています。

- **座標系** … 原資料は 841.92 × 595.32pt。この 842 × 595 の座標をそのまま使い、
  コンテナ幅に対する相対単位（`--u`）で全体を拡大縮小する。どの画面幅でもレイアウトは崩れない。
- **文字** … 画像化せず HTML のテキスト。位置と字送りは `pdftotext -bbox-layout` が返す
  1行ごとの座標から算出。コピーも検索もできる。
- **図形** … 角丸ボックス、棒グラフ、ピル、点線は CSS で作図。
- **吹き出し・矢印** … PDF を 216dpi で描画し、緑の連結成分だけを取り出して
  透過 PNG 化（`assets/deco/`）。
- **写真・イラスト** … PDF に埋め込まれた画像を抽出（`assets/img/`）。
  原資料で縦横比が調整されているものは、原本の描画領域に合わせて枠を計算。
- **積み上げ棒グラフ**（7ページ目）… 再エネと原子力の内訳は原本のグラフを
  ピクセル単位で計測して復元（九州 30.0 / 35.0、関西 17.0 / 34.6 ほか）。

原本のレンダリングと1枚ずつ重ねて確認し、グレースケールの平均差は 5.5/255。

## ビューアー

スライドの再現はそのままに、見るための仕組みを用意しています。

- **発表モード** … 全画面で1枚ずつ表示。画面の左右クリック・矢印キー・スワイプで送る。
  下のバーにページ番号と進捗、Esc で終了。
- **一覧** … 22枚のサムネイル。クリックでそのページへ。
- **章ナビ** … 表紙／01会社概要 〜 07クイズ。現在の章が自動でハイライトされる。
- **正解を隠す** … クイズ（20〜22ページ）の答えを伏せる。発表中に使う。
- **印刷** … 1ページに1枚で出力される（PDF保存も可）。

| キー | 動作 |
| --- | --- |
| `←` `→` `↑` `↓` `Space` | ページ送り |
| `Home` `End` | 最初・最後のページ |
| `G` | 一覧 |
| `F` | 発表モード |
| `Esc` | 発表モード／一覧を終了 |

## ファイル

```
index.html        22枚のスライド
css/style.css     ビューアーと、スライドの座標系・スタイル
js/main.js        ページ移動・発表モード・一覧表示・正解の表示切替
assets/img/       原資料から抽出した写真・イラスト
assets/deco/      吹き出し・矢印・プラス記号（透過PNG）
```

## 動かし方

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html` を直接ブラウザで開いても表示できます。
