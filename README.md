# 九州電力 ― 九州のエネルギーを知る

プレゼンテーションスライド（全22ページ）を、1ページのウェブサイトとして再構成したものです。

## 構成

| No. | セクション | 内容 |
| --- | --- | --- |
| – | ヒーロー / 目次 | 夜景ビジュアルと主要指標、全セクションへの導線 |
| 01 | 会社概要 | 設立・総販売電力量・持株会社化・資本金 |
| 02 | 他社との違い | 非化石電源比率の他社比較（横棒グラフ） |
| 03 | 地熱発電 | 資源量・設備容量、メリット／デメリット、バイナリー発電 |
| 04 | バイオマス発電 | 設備容量の比較、バイオマス混焼のしくみ |
| 05 | 太陽光発電 | 発電割合・日照時間の比較、出力制限と優先給電ルール |
| 06 | 産業との関係 | 半導体工場の誘致と「生まれる好循環」 |
| 07 | クイズ | 全3問。正誤判定・解説・スコア表示つき |

## 実装

- 依存ライブラリなしの静的サイト（HTML / CSS / JavaScript）
- スクロールに連動したフェードイン、グラフのアニメーション、数値のカウントアップ
- 現在地を示すナビゲーションハイライトと読み進みプログレスバー
- レスポンシブ対応（モバイルではハンバーガーメニュー）
- `prefers-reduced-motion` に対応し、アニメーションを抑制可能

## ファイル

```
index.html        ページ本体
css/style.css     スタイル
js/main.js        スクロール連動・クイズ
assets/img/       スライドから抽出した画像
```

## 動かし方

リポジトリのルートで簡易サーバーを立ち上げ、ブラウザで開きます。

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html` を直接ブラウザで開いても表示できます。

## 注記

掲載している数値は、もとになったプレゼンテーション資料の記載に基づく学習・発表用のものです。
画像はスライドに含まれていた素材を抽出して使用しています。
