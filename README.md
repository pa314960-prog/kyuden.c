# 九州電力｜九州のエネルギーを読む

九州電力についての発表資料（A4横・全22ページ）を、2つの形でウェブ化したものです。

🔗 公開ページ: https://pa314960-prog.github.io/kyuden.c/

| ページ | 内容 |
| --- | --- |
| `index.html` | **読みもの版**。スライドの枠を外し、ウェブページとして読める組版に再構成したもの |
| `slides.html` | **スライド版**。原資料のレイアウトを1ページずつ忠実に再現したもの |

2つは互いにリンクしています。

---

## 読みもの版（index.html）

16:9の白い板を並べるのではなく、ひとつづきの読みものとして組み直しています。
原資料の配色（グリーン、重要語句の赤、原子力の濃紺、黄色のマーカー）と
コンポーネント（カード、重要語句ボックス、優先給電ルールのピル、好循環の流れ図）は
そのまま引き継ぎました。

- 全画面の写真から始まり、目次を経て 01〜07 の章へ進む構成
- 中扉は独立したページではなく、章の見出しとして本文に溶かした
- グラフは画面に入ったところで伸び、数値がカウントアップする
- 積み上げ棒グラフの再エネ／原子力の内訳は、原資料のグラフを実測して復元
- クイズは選んで答え合わせができ、3問終えるとスコアが出る
- 画面幅に応じて1カラムに畳まれる

## スライド版（slides.html）

原資料の PDF から、各要素の位置・大きさ・色をすべて実測して組み直したものです。

- **座標系** … 原資料は 841.92 × 595.32pt。この 842 × 595 の座標をそのまま使い、
  コンテナ幅に対する相対単位（`--u`）で全体を拡大縮小する。
- **文字** … 画像化せず HTML のテキスト。位置と字送りは `pdftotext -bbox-layout` が返す
  1行ごとの座標から算出。
- **図形** … 角丸ボックス、棒グラフ、ピル、点線は CSS で作図。
- **吹き出し・矢印** … PDF を 216dpi で描画し、緑の連結成分だけを取り出して
  透過 PNG 化（`assets/deco/`）。
- **写真・イラスト** … PDF に埋め込まれた画像を抽出（`assets/img/`）。
  原資料で縦横比が調整されているものは、原本の描画領域に合わせて枠を計算。

原本のレンダリングと1枚ずつ重ねて確認し、グレースケールの平均差は 5.5/255。

**ビューアー**

- **発表モード** … 全画面で1枚ずつ表示。左右クリック・矢印キー・スワイプで送る
- **一覧** … 22枚のサムネイル。クリックでそのページへ
- **正解を隠す** … クイズの答えを伏せる
- **印刷** … 1ページに1枚で出力される

| キー | 動作 |
| --- | --- |
| `←` `→` `↑` `↓` `Space` | ページ送り |
| `Home` `End` | 最初・最後のページ |
| `G` | 一覧 |
| `F` | 発表モード |
| `Esc` | 終了 |

## ファイル

```
index.html        読みもの版
slides.html       スライド版（原資料の再現）
css/site.css      読みもの版のスタイル
css/slides.css    スライド版の座標系とスタイル
js/site.js        読みもの版の挙動（出現アニメーション・グラフ・クイズ）
js/slides.js      スライド版の挙動（ページ移動・発表モード・一覧）
assets/img/       原資料から抽出した写真・イラスト
assets/deco/      吹き出し・矢印・プラス記号（透過PNG）
```

## 動かし方

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`index.html` を直接ブラウザで開いても表示できます。
